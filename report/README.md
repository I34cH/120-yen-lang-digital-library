# Báo cáo cuối kỳ (LaTeX — điểm cộng +0,5)

Thư mục này chứa mã nguồn LaTeX (`.tex`, hình ảnh, `.bib`) và file PDF biên dịch cuối cùng của báo cáo Project nhóm **120 YÊN LÃNG**.

## Lưu ý theo yêu cầu học phần
- Nộp đủ **mã nguồn LaTeX** để biên dịch lại được cùng file **PDF** kết quả.
- Không chèn toàn bộ báo cáo dưới dạng ảnh/PDF vào tệp `.tex`.
- Nếu sử dụng mẫu LaTeX có sẵn, ghi rõ nguồn trong báo cáo.
- Các minh chứng dài (SQL, log concurrency, EXPLAIN, ảnh kiểm thử) đặt trong `docs/` và dẫn liên kết/tham chiếu từ báo cáo để tránh lặp lại.
